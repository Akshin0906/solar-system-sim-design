# Code of conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. The versioned canonical text applies in full.

In practical terms, participation in repository issues, pull requests, reviews,
and other project spaces must remain respectful, constructive, and free from
harassment, discrimination, threats, sexualized conduct, deliberate intimidation,
and publication of another person's private information. Technical disagreement
is welcome; personal attacks are not.

## Reporting and enforcement

For conduct hosted by GitHub, use GitHub's report, block, and abuse-reporting
controls when appropriate. To ask the project maintainer to arrange a private
reporting channel, open a
[conduct contact request](https://github.com/Akshin0906/solar-system-sim-design/issues/new?template=conduct_contact.yml)
without naming people or describing the incident publicly.

The maintainer is responsible for fair, proportionate enforcement and for
protecting a reporter's privacy as far as reasonably possible. Responses may
include correction, warning, temporary restriction, or permanent exclusion from
project spaces, following the Contributor Covenant's community-impact guidance.
