# Changelog

Notable project releases are recorded here. The simulator follows semantic
versioning for portfolio release milestones; scientific/model limitations remain
documented in `DATA_SOURCES.md` and `ROCKETS.md`.

## [1.0.0] - 2026-08-06

### Highlights

- Interactive, responsive React Three Fiber solar-system exploration with dated
  orbital motion, scale lenses, search, body inspection, and camera presets.
- Guided experiences, model-driven what-if scenarios, and educational direct,
  Hohmann, and Lambert mission previews.
- Visible scientific provenance, validation ranges, approximation disclosures,
  and asset attribution.
- Installable app-shell PWA with bounded on-demand texture caching.

### Release quality

- Strict TypeScript and accessibility linting, scoped unit coverage, independent
  scientific verifiers, scenario performance budgets, and cross-browser Playwright
  coverage.
- Recoverable WebGL failures, privacy-conscious client diagnostics, immutable
  deployment identity, and stale-artifact deployment protection.
- Repository governance, security reporting, dependency maintenance, and a
  documented AI-assistance/technical-ownership policy.
